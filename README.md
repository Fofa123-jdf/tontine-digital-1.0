# Tontine Digital 1.0 — Version vierge

Cette version conserve l’interface de démonstration mais démarre sans membres, tontines, cotisations, paiements, commissions, notifications ou historiques fictifs.

- `index.html` : accueil avec accès membre et administration
- `membre/index.html` : espace membre
- `admin/index.html` : espace administration

Important : il s’agit toujours d’une démo statique. Les données sont locales au navigateur et les paiements ne sont pas réels.
